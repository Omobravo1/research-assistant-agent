# AI Research Assistant Agent

## Overview

An AI-powered Research Assistant built with Streamlit, LangChain, OpenAI, and FAISS.

This application can:

- Search the web
- Read uploaded PDF documents
- Answer research questions
- Remember previous conversations
- Generate research reports
- Retrieve information using Retrieval-Augmented Generation (RAG)

---

## Tech Stack

- Python
- Streamlit
- OpenAI
- LangChain
- FAISS
- Tavily Search
- PyPDF
